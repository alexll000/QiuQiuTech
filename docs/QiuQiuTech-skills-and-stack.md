- Next.js
- React
- Tailwind CSS v4
- shadcn/ui
- Motion for restrained interaction
- chart library for metrics modules where needed

## 5. Recommended UI Inspiration Sources

- React Bits: for selective motion and hero emphasis
- shadcn/ui: for base design system
- Magic UI: for tasteful animated enhancement
- Aceternity UI: for isolated premium accent modules
- 21st.dev: for layout and component inspiration
- Preline UI: for admin and ops interface structure

## 6. Build Principles

- content platform first, marketing page second
- keep the design premium, clean, and restrained
- use animation only to improve hierarchy and polish
- favor structured forms and repeatable content modules
- keep admin efficient and frontend editorial
