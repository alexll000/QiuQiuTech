# QiuQiuTech 首页重设计 v2

## 1. 设计目标

- **解决空白问题**：消除图 1 红框区域的巨大空白
- **文案务实化**：用营销人听得懂的语言，避免抽象概念
- **信息密度优化**：平衡内容展示与视觉呼吸感
- **统一 UI 风格**：全站设计语言一致

## 3. 区块详细设计

### 3.1 Hero Section（价值主张）

**标题**：
```
发现营销机会，对接优质资源
```

**副标题**：
```
每日更新 100+ 品牌案例、热点趋势、合作需求
```

**CTA 按钮**：
```
[浏览精选内容]  [发布合作需求]
```

**设计说明**：
- 去掉抽象的三卡片设计
- 直接给出价值主张和行动入口
- 背景可用渐变色或简洁插画

### 3.2 营销热度趋势（左侧区域）

#私域运营    #品牌联名      #KOL投放

**设计说明**：
- 用趋势关键词填充原空白区域

## 5. UI 设计规范

### 5.1 色彩系统

**主色调**：
- 品牌色：`#2563EB`（蓝色）
- 辅助色：`#10B981`（绿色，用于增长/热度）
- 警示色：`#EF4444`（红色，用于高热度）

**中性色**：
- 标题文字：`#111827`
- 正文文字：`#374151`
- 辅助文字：`#6B7280`
- 边框/分割线：`#E5E7EB`
- 背景灰：`#F9FAFB`

### 5.2 字体规范

**字体栈**：
```css
font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, 'Helvetica Neue', Arial, sans-serif;
```

**字号层级**：
- 页面标题：32px / font-weight: 700
- 区块标题：24px / font-weight: 600
- 卡片标题：16px / font-weight: 600
- 正文：14px / font-weight: 400
- 辅助文字：12px / font-weight: 400

### 5.3 间距系统

**区块间距**：
- 大区块之间：64px
- 小区块之间：48px
- 区块内部：32px

**内容间距**：
- 卡片间距：24px
- 文字行间距：1.5
- 元素间距：16px / 12px / 8px

### 5.4 圆角规范

- 大卡片/区块：16px
- 小卡片/按钮：12px
- 标签/小元素：8px
- 按钮（pill 风格）：9999px

## 6. 响应式设计

### 6.1 桌面端（≥1280px）
- 双栏布局：趋势（左，40%）+ 项目（右，60%）
- 案例卡片：4 列网格
- 导航：完整显示

### 6.2 平板端（768px - 1279px）
- 单栏布局：趋势在上，项目在下
- 案例卡片：2 列网格
- 导航：汉堡菜单

### 6.3 移动端（<768px）
- 单栏布局
- 案例卡片：1 列
- 趋势图表简化为迷你图
- 底部固定导航栏

## 7. 交互细节

### 7.1 Tab 切换
- 选中状态：底部 2px 品牌色边框 + 文字加粗
- 切换动画：内容淡入淡出（200ms）
- URL 同步：?tab=short-video

### 7.2 卡片悬停
- 阴影提升：`box-shadow: 0 10px 40px rgba(0,0,0,0.1)`
- 轻微上移：`transform: translateY(-4px)`
- 过渡时间：300ms ease-out

### 7.3 加载状态
- 骨架屏：灰色占位块脉冲动画
- 加载更多：底部 Spinner + "加载中..."

## 9. 与原设计对比总结

### 解决的问题

| 问题 | 解决方案 |
|------|----------|
| 趋势区域下方巨大空白 | 添加「热门话题」关键词列表填充 |
| Hero 文案过于抽象 | 改为直接的价值主张和行动入口 |
| 三卡片文案用户看不懂 | 删除三卡片，简化 Hero 设计 |
| 信息密度不均 | 重新平衡左右栏内容高度 |
| 缺乏明确的 CTA | 每个区块都添加清晰的行动入口 |

### 保留的核心功能

- ✅ 营销热度趋势图表
- ✅ 精选营销项目列表
- ✅ 精选案例展示
- ✅ 分类 Tab 切换

### 删除的冗余内容

- ❌ 抽象的三卡片价值主张
- ❌ 空白区域
- ❌ 过于复杂的文案
