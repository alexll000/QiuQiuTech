# QiuQiuTech 首页重设计 v3（最终版）

## 1. 设计目标与原则

### 1.1 核心目标
- ✅ 保留核心功能区：营销热度趋势 + 精选营销项目 + 精选案例
- ✅ 文案基于真实场景，去除抽象概念
- ✅ UI 设计统一（圆角、间距、字体、色彩）
- ✅ 消除布局缺陷（空白区域、密度不均）

### 1.2 文案原则
- **直接**：不说"把内容判断与合作决策放进同一条工作流"，改为"发现营销机会，对接优质资源"
- **量化**：不说"每日追踪品牌案例"，改为"每日更新 100+ 品牌案例"
- **行动导向**：每个区块都有明确的 CTA 按钮
- **真实场景**：用营销人日常工作中的语言

## 4. UI 设计规范（统一标准）

### 4.1 色彩系统

**主色调**：
- 品牌蓝：`#2563EB`
- 成功绿：`#10B981`（用于上涨/热度）
- 警示红：`#EF4444`（用于下跌/高风险）

**中性色**：
- 标题文字：`#111827`
- 正文文字：`#374151`
- 辅助文字：`#6B7280`
- 占位文字：`#9CA3AF`
- 边框/分割线：`#E5E7EB`
- 背景灰：`#F9FAFB`
- 深色背景：`#111827`（Footer）

### 4.2 字体规范

**字体栈**：
```css
font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, 'Helvetica Neue', Arial, sans-serif;
```

**字号层级**：
- 页面标题：32px / font-weight: 700 / line-height: 1.2
- 区块标题：24px / font-weight: 600 / line-height: 1.3
- 卡片标题：16px / font-weight: 600 / line-height: 1.5
- 正文：14px / font-weight: 400 / line-height: 1.6
- 辅助文字：12px / font-weight: 400 / line-height: 1.5

### 4.3 间距系统

**区块间距**：
- 大区块之间：64px（如 Hero 与内容区之间）
- 小区块之间：48px（如两个内容区之间）
- 区块内部：32px（如标题与内容之间）

**内容间距**：
- 卡片间距：24px（网格间距）
- 文字行间距：1.5（段落）/ 1.3（标题）
- 元素间距：16px（相关元素）/ 12px（紧凑元素）/ 8px（标签）

### 4.4 圆角规范

- 大卡片/容器：12px（#E5E7EB 边框）
- 小卡片/按钮：8px
- 标签/小元素：4px
- 按钮（pill 风格）：9999px

### 4.5 阴影规范

**卡片悬停阴影**：
```css
box-shadow: 0 10px 40px rgba(0, 0, 0, 0.1);
transform: translateY(-4px);
transition: all 300ms ease-out;
```

**卡片默认阴影**：
```css
box-shadow: none;
border: 0.5px solid #E5E7EB;
```

## 6. 交互细节

### 6.1 Tab 切换
- 选中状态：底部 2px 品牌色边框 + 文字加粗
- 切换动画：内容淡入淡出（200ms）
- URL 同步：?tab=short-video

### 6.2 卡片悬停
- 阴影提升：`box-shadow: 0 10px 40px rgba(0,0,0,0.1)`
- 轻微上移：`transform: translateY(-4px)`
- 过渡时间：300ms ease-out

### 6.3 加载状态
- 骨架屏：灰色占位块脉冲动画（#F3F4F6）
- 加载更多：底部 Spinner + "加载中..."

## 7. 与原设计对比总结

### 解决的问题

| 问题 | 解决方案 |
|------|----------|
| 趋势区域下方巨大空白 | 添加「热门话题」关键词列表填充，利用空间 |
| Hero 文案过于抽象 | 改为直接的价值主张和行动入口 |
| 三卡片文案用户看不懂 | 删除三卡片，简化 Hero 设计 |
| 信息密度不均 | 重新平衡左右栏内容高度，统一卡片样式 |
| 缺乏明确的 CTA | 每个区块都添加清晰的行动入口 |
| UI 设计不统一 | 定义统一的色彩、字体、间距、圆角、阴影规范 |

### 保留的核心功能

- ✅ 营销热度趋势图表
- ✅ 精选营销项目列表
- ✅ 精选案例展示
- ✅ 分类 Tab 切换

### 删除的冗余内容

- ❌ 抽象的三卡片价值主张
- ❌ 空白区域
- ❌ 过于复杂的文案
