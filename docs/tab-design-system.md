# QiuQiuTech Tab 设计系统

## 1. 设计原则

### 1.1 核心目标
- **减少冗余**：避免在首页堆砌所有内容
- **信息分层**：首页做策展和入口，详情页做深度展示
- **一致体验**：全平台 Tab 交互模式统一
- **可扩展性**：支持后台配置和动态增减

### 1.2 Tab 分类逻辑

**维度 1：内容分类 Tab**
- 按业务类型：案例 / 玩法 / 专题 / 需求
- 按行业：美妆 / 3C / 食品 / 服饰...
- 按平台：抖音 / 小红书 / 视频号 / B站...

**维度 2：时间维度 Tab**
- 最新 / 本周 / 本月 / 季度

**维度 3：热度维度 Tab**
- 热门 / 推荐 / 最新 / 讨论中

**维度 4：状态维度 Tab**
- 进行中 / 已结束 / 预告（专题）
- 待审核 / 已发布 / 已驳回（后台）

**Tab 结构**：
```text
┌──────────────────────────────────────┐
│  [精选] [案例] [玩法] [专题] [需求]  │
```

- **需求**：最新对接需求（3-5 条）

## 4. Tab 交互规范

### 4.1 视觉样式

**选中状态**：
- 底部边框高亮（2px，品牌色）
- 字体加粗
- 背景色微变化（可选）

**未选中状态**：
- 灰色文字
- 无边框

**Hover 状态**：
- 背景色变化
- 文字颜色变化

### 4.2 交互行为

**切换方式**：
- 点击 Tab 切换内容
- 支持 URL 参数同步（?tab=featured）
- 支持浏览器前进/后退

**内容加载**：
- 首次加载：SSR 渲染
- Tab 切换：CSR 加载（SPA 体验）
- 缓存已加载的 Tab 内容（keep-alive）

**响应式**：
- 桌面端：横向排列
- 平板端：横向滚动
- 移动端：横向滚动 或 下拉菜单

### 4.3 组件实现（shadcn/ui）

```tsx
// 使用示例
import { Tabs, TabsContent, TabsList, TabsTrigger } from "@/components/ui/tabs"

<Tabs defaultValue="featured">
  <TabsList>
    <TabsTrigger value="featured">精选</TabsTrigger>
    <TabsTrigger value="cases">案例</TabsTrigger>
    <TabsTrigger value="playbooks">玩法</TabsTrigger>
    <TabsTrigger value="topics">专题</TabsTrigger>
  </TabsList>
  
  <TabsContent value="featured">
    {/* 精选内容 */}
  </TabsContent>
  <TabsContent value="cases">
    {/* 案例内容 */}
  </TabsContent>
</Tabs>
```
