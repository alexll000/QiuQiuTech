# Review SOP

最后更新：2026-05-08 10:05 (UTC+8)

## 适用范围

- 投稿审核（`submissions`）
- 合作需求审核（`partnership_requests`）
- 合作申请处理（`match_applications`）

## 审核流程

1. 进入待审核队列（默认筛选 `pending_review`）
2. 执行通过或驳回
3. 记录审核信息：
   - `reviewed_by`
   - `reviewed_at`
   - `review_note`
4. 通过后可发布（`published`）

## 驳回规则

驳回必须填写原因，建议使用模板：

- 信息不完整（缺主图/缺正文/缺联系方式）
- 内容不合规（版权/敏感/广告违规）
- 质量不达标（案例细节不足/方法论不可复用）
- 对接意图不清（合作对象/周期/预算不明确）

## 发布与下线

1. 发布前复核 SEO 字段和标签。
2. 下线必须记录原因并可回溯。
3. 已发布内容修改后，重新进入审核流。
