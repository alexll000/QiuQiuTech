# QiuQiuTech 整体站点架构设计方案

## 一、设计目标与原则

### 1.1 设计目标
基于 QiuQiuTech 营销行业聚合与对接平台的业务特性，设计一个简洁高级、逻辑清晰、信息密度合理的整体站点架构。

### 1.2 核心原则
- **简单高级**：对标 SocialBeta，简洁布局、精致细节、内容优先
- **逻辑合理**：导航清晰、分类明确、用户心智模型匹配
- **信息密度适中**：在有限空间内展示有价值信息，避免信息过载
- **保留核心**：保留现有红色标注内容（营销热度趋势、精选营销项目、实时营销事件）
- **差异化**：突出 QiuQiuTech 的合作对接特色

### 1.3 对标分析：SocialBeta 特点
- **布局**：单栏主导 + 侧边栏辅助，层次清晰
- **导航**：顶部固定导航 + 底部快捷入口
- **内容**：卡片式展示，信息密度高但不拥挤
- **视觉**：黑白为主 + 品牌色点缀，克制用色
- **交互**：悬停反馈温和，动画克制

### 2.2 导航结构设计

#### 顶部主导航（固定）

**参考行业惯例优化后的导航：**

```
┌─────────────────────────────────────────────────────────────┐
│  [Logo]  首页  文章  案例  营销事件  玩法拆解  专题策展  合作对接  招聘  榜单趋势  [搜索]  [登录]  [提交内容] │

```

**导航项说明：**
- **首页**：平台概览，核心价值展示
- **文章**：行业资讯、观点、方法论（参考数英网"文章"）
- **案例**：创意案例、项目展示（参考数英网"项目"）
- **营销事件**：实时追踪，时间线展示
- **玩法拆解**：方法论，按平台分类
- **专题策展**：主题聚合，运营策划
- **合作对接**：差异化核心，供需匹配
- **招聘**：行业人才对接（参考数英网"招聘"）
- **榜单趋势**：数据驱动，排行榜
- **搜索**：全局搜索入口
- **登录**：用户登录/注册
- **提交内容**：UGC 入口

### 3.2 首页板块优先级

| 板块 | 优先级 | 说明 |
|------|--------|------|
| Hero 价值展示区 | P0 | 核心价值传达 |
| 营销热度趋势 | P0 | 保留红色标注 |
| 精选营销项目 | P0 | 保留红色标注 |
| 实时营销事件 | P0 | 保留红色标注 |

| 合作需求精选 | P1 | 差异化特色 |

### 3.3 首页视觉风格

**对标 SocialBeta 的简单高级风格：**
- **配色**：白色背景 + 深色文字 + 品牌色（Teal）点缀
- **留白**：充足的垂直间距，避免拥挤
- **卡片**：圆角 8px，细微阴影，边框克制
- **字体**：中文使用思源黑体，英文使用 Inter
- **图标**：线性图标，简洁统一
- **动效**：悬停时轻微上移 + 阴影加深，动画时长 200ms

### 4.2 文章卡片设计

**卡片信息层级：**
1. **封面图**（16:9，左侧）
2. **标签**（头条/精选/热文，右上角）
3. **标题**（加粗，2行截断）
4. **摘要**（灰色，2行截断）
5. **作者信息**（头像 + 昵称）
6. **元信息**（底部，灰色小字）
   - 发布时间
   - 阅读量
   - 收藏数
   - 来源标注（官方/抓取/用户投稿）

### 4.3 Tab 切换逻辑

- **全部**：显示所有文章，按推荐权重排序
- **头条**：编辑推荐的头条文章，置顶显示
- **精选**：编辑精选的优质文章
- **热文**：按阅读量和互动量排序的热门文章
- **特色专栏**：专栏作者的文章合集
- **推荐收藏夹**：用户收藏的优质文章

## 十二、页面间逻辑关系

### 12.1 导航逻辑

```
首页
  ↓ 点击"内容中心"
内容中心
  ↓ 点击"营销快讯" Tab
  → 显示营销快讯列表
  ↓ 点击某个内容
  → 内容详情页

首页
  ↓ 点击"营销事件"
营销事件
  ↓ 点击"品牌动态" Tab
  → 显示品牌动态时间线
  ↓ 点击某个事件
  → 事件详情页

首页
  ↓ 点击"合作对接"
合作对接
  ↓ 点击"发布需求"
  → 发布需求表单
  ↓ 提交后
  → 我的对接（用户中心）
```

### 12.2 内容关联逻辑

- **内容中心** → **专题策展**：内容可关联到多个专题
- **营销事件** → **内容中心**：事件可生成营销快讯
- **玩法拆解** → **内容中心**：玩法可关联到创意案例
- **合作对接** → **内容中心**：成功案例可生成创意案例
- **榜单趋势** → **内容中心**：榜单品牌可关联到品牌动态

### 12.3 用户路径设计

**内容消费者路径：**
```
首页 → 营销热度趋势 → 榜单趋势 → 品牌榜单 → 品牌动态 → 内容中心 → 创意案例 → 案例详情
```

**内容创作者路径：**
```
首页 → 提交内容 → 投稿表单 → 我的投稿 → 审核结果 → 内容中心
```

**合作对接路径：**
```
首页 → 合作对接 → 浏览需求 → 需求详情 → 联系发布者 → 我的对接
```
